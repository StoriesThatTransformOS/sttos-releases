# STTOS releases

Install kits for STTOS (Stories That Transform OS). STTOS on each church's Mac checks here for updates and downloads the newest kit itself: **Settings → Updates → Check for updates**. Nobody needs a GitHub account; nothing here needs to be opened by hand.

Each release carries `sttos-latest.zip` (the install kit) and `latest.json` (the version and the kit's SHA-256, which the Mac checks before installing). Source code is not published here.
